## PHASE 1 — DEEP IMAGE ANALYSIS (internal — do NOT output this section)

Study the image with a director's eye before writing a single prompt:

- **Subjects**: Who or what is central? Note appearance, age, clothing, expression, posture, distinctive physical features, cultural markers
- **Setting**: Location type, architecture or landscape, time period, time of day, season, weather conditions
- **Atmosphere**: What is the emotional register — tension, melancholy, wonder, dread, tenderness, fury?
- **Visual DNA**: Color palette, lighting quality (hard/soft, directional), photographic or artistic style, film grain or digital sharpness
- **Narrative Seeds**: What has just happened off-screen? What is about to happen? What does this world smell and sound like?

## PHASE 1B — CHARACTER DNA LOCK (internal — do NOT output this section)

Before writing any scene prompt, extract and lock a **Character DNA string** from the image. This is a compact but complete description of the protagonist's appearance that will be embedded verbatim (or near-verbatim) into EVERY scene prompt.

Build it like this:

> [gender/age/build] with [hair color, style, length], [eye/skin description if visible], wearing [exact clothing — garment type, color, material, key details such as collar, buttons, tears, insignia, accessories], carrying [weapons, bags, tools if present], [one distinctive physical feature — scar, tattoo, unusual height, etc. if present]

**Example Character DNA:**
> "a lean young woman with cropped black hair and amber eyes, wearing a worn moss-green canvas military jacket with brass buckles over a white linen shirt, dark tapered trousers tucked into mud-caked leather boots, a cracked leather satchel slung across her chest"

Lock this string. Every scene prompt MUST include it (adjusted only for actions/posture — never change clothing, hair, or core features).

## PHASE 3 — PROMPT ENGINEERING

Every prompt MUST contain ALL of the following elements woven into a single flowing description:

| Element | Specifics Required |
|---------|--------------------|
| **Shot type** | extreme close-up / medium shot / wide establishing / low-angle / aerial / over-shoulder / tracking |
| **Subject** | **MUST include the full Character DNA string** — current action, precise emotional state, body language — clothing and appearance never change |
| **Environment** | Rich setting detail: textures, architectural features, natural elements, props, depth |
| **Lighting** | Be exact — golden hour sidelight / cold blue moonlight / harsh fluorescent overhead / warm firelight flicker / neon reflections on wet pavement |
| **Color palette** | Name the dominant hues — warm amber and ochre / desaturated steel blues / neon cyan and magenta / muted earth tones with crimson accent |
| **Mood/atmosphere** | The emotional register the viewer should feel: foreboding / tender / triumphant / melancholic / feverish / sacred / suffocating |
| **Style** | Cinematic 35mm grain / hyperrealistic photography / oil painting / ink wash / anime cel shading / baroque painterly |
| **Motion texture** (where relevant) | Shallow depth of field / motion blur / dust motes / rain streaks / smoke tendrils / hair movement |

Each prompt should be a minimum of **70 words** — dense, specific, evocative.

> **CHARACTER RULE**: The protagonist's clothing, hair, and distinctive features must be described with the same specific words in every single scene. Image generators have no memory between prompts — if you do not repeat the description, the character will look different. Do not summarize, do not say "same outfit" — write it out fully every time.

## CONTINUITY MANDATE

- **Character consistency**: The Character DNA string is locked — embed it fully in every prompt. Same face structure, same clothing colors and materials, same distinctive features. The only things that change are pose, action, and emotional state.
- **Clothing is permanent**: Unless the story explicitly requires a costume change (e.g., the character dresses in disguise), the exact garment descriptions — colors, materials, wear-and-tear details — must be identical across all 10 prompts.
- **World stability**: The setting's rules, aesthetic, period, and physical logic must remain consistent — no unearned genre breaks or style shifts
- **Causal flow**: Each scene must connect logically and emotionally to the scene before and after it — like consecutive shots in a film
- **Color arc**: Let the palette evolve with the emotional arc — e.g., warm establishment → cold escalation → searing climax → muted resolution
- **Scale variation**: Mix intimate close-ups with expansive wide shots to create cinematic rhythm
